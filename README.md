# Dairy-Multi-Objective-Optimization-
The project characterize the trade-off between milk revenue and conception costs and to identifies body condition score (BCS) profiles during lactation that jointly maximize milk revenue while minimizing conception costs in dairy cows by using the Non Dominated Sorting Genetic Algorithm II (NSGA II).

Final_data_kg is the data used in the study. 
cost of day open shows the calculation involves in estimating cost due to delayed conception.
milk price2023 shows the process involved in calculating avergae milk price. 
MOO 11 vars is the R code use tosummarize results and get parameters for MOO. 
MOO_kg_data is the python code and baseline result. 
Files with sensitivity in their names are the sensitivity analysis.
